## 📐 Section-by-Section Generation Guide

### 1. Deep Explanation (400-500 words total)

**Paragraph 1 (Intro + What):**
- Define the concept clearly
- Explain what it is
- Why it's important
- Real-world relevance
- **Word count: 150-200**

**Paragraph 2 (How + When):**
- How it works
- When to use it
- Context and situations
- Relationship to other concepts
- **Word count: 150-200**

**Paragraph 3 (Applications + Takeaway):**
- Real-world applications
- Key insights
- Helpful perspective
- Summary/takeaway
- **Word count: 100-150**

**Template:**
```
Paragraph 1: This [concept] is [definition]. It refers to [characteristics]. 
[Concept] is important because [why]. Understanding [concept] helps you 
[practical benefit]. In everyday English, [example context].

Paragraph 2: [Concept] works by [mechanism]. You use it when [situations]. 
The key distinction is [difference from related concepts]. For instance, 
[example]. This is particularly important when [context].

Paragraph 3: In real-world contexts, [application 1] and [application 2] 
show how [concept] is essential. The main takeaway is [key insight]. 
Learning [concept] significantly improves [skill/understanding].
```

### 2. Formation Structure (5 steps)

**Each step includes:**
- Step number
- Step title (short, memorable)
- Detailed explanation (1-2 sentences)
- 2-3 concrete examples
- The rule/pattern

**Template:**
```json
{
  "step": 1,
  "title": "What is [step about]?",
  "explanation": "Description of this step...",
  "examples": ["example1", "example2", "example3"],
  "rule": "The pattern or rule for this step..."
}
```

**Tips:**
- Keep steps simple and sequential
- Each step builds on previous
- Use consistent formatting
- End with clear rule statement

### 3. Real-World Examples (10+ examples)

**Each example includes:**
- Complete sentence in English
- Translation to another language (optional)
- Highlighted nouns/words
- Brief explanation (1-2 sentences)
- Context (what situation)
- Difficulty level (Easy/Medium/Hard)

**Template:**
```json
{
  "id": 1,
  "sentence": "The cat jumped over the fence.",
  "translation": "[Language]: [Translation]",
  "highlighted_items": ["cat", "fence"],
  "explanation": "Both 'cat' and 'fence' are concrete nouns because you can see and touch them.",
  "context": "Describing an action with physical objects",
  "difficulty": "Easy"
}
```

**Distribution:**
- 3-4 Easy examples (beginner level)
- 3-4 Medium examples (intermediate)
- 3-4 Hard examples (advanced/complex)

### 4. Grammar Rules (5 rules)

**Each rule includes:**
- Rule name (descriptive)
- Full explanation (2-3 sentences)
- DO example (correct)
- DON'T example (incorrect)
- 3 key points as bullet list

**Template:**
```json
{
  "id": 1,
  "rule_name": "Descriptive rule name",
  "explanation": "Detailed explanation of the rule with context...",
  "do_example": "Correct sentence using the rule.",
  "dont_example": "Incorrect sentence violating the rule.",
  "key_points": [
    "First key point",
    "Second key point",
    "Third key point"
  ]
}
```

**Tips:**
- Rules should be actionable
- Examples should be clear and contrasting
- Key points should be memorable
- Order rules from basic to advanced

### 5. Common Mistakes (8 mistakes)

**Each mistake includes:**
- The mistake (what students write)
- The correction (what they should write)
- Explanation (why it's wrong)
- Rule violated (which rule)

**Template:**
```json
{
  "id": 1,
  "mistake": "Incorrect sentence students write",
  "correction": "Corrected sentence",
  "explanation": "This is wrong because... The correct way is... because...",
  "rule_violated": "Name of the grammar rule"
}
```

**Distribution:**
- 2-3 basic mistakes (obvious errors)
- 2-3 intermediate mistakes (common errors)
- 2-3 advanced mistakes (tricky/nuanced errors)

### 6. Writing Exercise

**Includes:**
- Exercise type (creative, narrative, descriptive, analytical)
- Clear prompt (what to write about)
- Guidelines (2-3 specific requirements)
- Sample answer (model response)
- Evaluation criteria (3-4 items to check)

**Template:**
```json
{
  "type": "descriptive",
  "prompt": "Write 100-150 words describing [topic]. Use at least [number] [grammar concept].",
  "guidelines": [
    "Specific requirement 1",
    "Specific requirement 2",
    "Specific requirement 3"
  ],
  "sample_answer": "Full sample response demonstrating all guidelines...",
  "evaluation_criteria": [
    "Is the grammar concept used correctly?",
    "Is the writing clear and coherent?",
    "Does it meet the word count requirement?"
  ]
}
```

### 7. Reading Comprehension (1-2 passages)

**Each passage includes:**
- Title
- Full text (200-300 words)
- Highlighted items with explanations
- 4 comprehension questions

**Question template:**
```json
{
  "id": 1,

  "options": ["Option A", "Option B", "Option C", "Option D"],
  "correct_answer": 0,
  "explanation": "Why A is correct and others are not..."
}
```

### 8. Pronunciation Guide

**For each word:**
- The word
- IPA phonetic notation
- Simplified pronunciation (like "AP-ul")
- Audio tips (how to pronounce)
- Common mistakes (what people do wrong)

**Template:**
```json
{
  "word": "example",
  "ipa": "/ɪɡˈzɑːmpl/",
  "pronunciation": "ig-ZAM-pul",
  "audio_tips": "Stress the second syllable. The 'a' sounds like...",
  "common_mistakes": "Many people pronounce it as... instead of..."
}
```

### 9. Practice Questions (15 total)

**Easy (5 questions):**
- Basic multiple choice
- Simple identification
- Direct application
- One correct answer is obvious

**Medium (5 questions):**
- Requires application
- Fill in the blank
- Context-based
- Multiple similar options

**Hard (5 questions):**
- Analysis required
- Advanced application
- Multiple correct interpretations
- Requires deep understanding

**Question template:**
```json
{
  "id": 1,
  "question": "The question text here?",
  "question_type": "multiple-choice",
  "options": ["Option 1", "Option 2", "Option 3", "Option 4"],
  "correct_answer": "Option 1",
  "explanation": "Why this is correct. This teaches the student..."
}
```

## 💡 Quality Tips

### Content Quality
- Use real-world, relevant examples
- Ensure accuracy in grammar rules
- Provide clear explanations
- Make mistakes realistic (what students actually do)
- Sample answers should be model responses
- Videos should be from reputable sources

### Writing Quality
- Clear, simple sentences
- Active voice when possible
- Avoid jargon without explanation
- Use consistent terminology
- Break long explanations into paragraphs
- Use bullet points for lists

### Consistency
- Same structure for all types
- Similar difficulty progression
- Consistent formatting
- Same emoji/color scheme per part
- Similar example styles
- Matching video quality/style
